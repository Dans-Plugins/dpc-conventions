# DPC Conventions

This repository documents the standards and conventions used across DPC (Dans Plugins Community) projects. It uses [Medieval Factions](https://github.com/Dans-Plugins/Medieval-Factions) as the flagship reference implementation.

The goal is to bring every plugin in the organization to the same level of completeness and quality as Medieval Factions.

## Contents

- [README Structure](docs/README_STRUCTURE.md) – Standard sections every DPC plugin README should contain
- [Documentation Practices](docs/DOCUMENTATION_PRACTICES.md) – What to document and where (in-repo files vs. wiki)
- [Contributing Standards](docs/CONTRIBUTING_STANDARDS.md) – What a complete `CONTRIBUTING.md` should include
- [Testing and CI](docs/TESTING_AND_CI.md) – Testing practices and continuous-integration setup
- [Release Automation](docs/RELEASE_AUTOMATION.md) – GitHub Action to build and attach a JAR to a release
- [GitHub Coding Agent Prompt](CLAUDE_PROMPT.md) – Ready-to-use prompt for aligning a plugin repo with these conventions

## Reference Implementation

[Medieval Factions](https://github.com/Dans-Plugins/Medieval-Factions) is the flagship plugin for the community and acts as the source of truth for all conventions described here.

## Contributing

If you would like to propose a new convention or update an existing one, please open an issue or pull request in this repository.
